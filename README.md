# BEARBULLS preview

Paper crowns, GPU bricks, founder pagers and an oversized ESC key.

This is the public art explorer and mock-USDG rehearsal for BEARBULLS on Robinhood testnet. No real-money mint is open. Paid pricing and launch terms are undecided.

- [Project alpha and updates](https://github.com/bearbull-click/bearbull-click)
- [Dated testnet proof](https://github.com/bearbull-click/bearbull-click/blob/main/PROOF.md)
- [X](https://x.com/bearbullsclick)

`site.zip` contains the reviewed static website, its browser code, the curated v0.25 media, and public verification evidence. The Pages workflow checks its SHA-256 digest before deploying it. It excludes deployment consoles, private planning documents and wallet credentials.

The explorer can show a universe of 10,000 specimens. The current testnet rehearsal registers 100 curated specimens; those are different counts. Its mock USDG has no monetary value. OpenSea display remains unverified. BEARBULLS is independent and has no Robinhood affiliation.

Bundled third-party code retains its license notice. Public availability does not grant a new blanket license to collection artwork.
